## 🕹️ How to Play
* **Arrow Keys** to move the paddle.
  
## 📝 Game Description
This is a game I built using Construct 3. Your goal is to move the paddle left or right to bounce the ball in play and to break all the bricks!

## ✨ Features
* Fast-paced platforming action
* 2 different levels based on difficulty
* Fully playable on mobile devices and desktop browsers
